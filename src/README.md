# Крестики-нолики в процедурном стиле на Java

Учебный проект на Java, предназначенный для практики базовых концепций языка,
практического закрепления знаний по JavaCore.

## Description

Проект создан в рамках самостоятельного изучения Java.  

Основные цели:

- отработка базового синтаксиса Java
- практика написания чистого кода в процедурном стиле

## Technologies

- Java 21
- IntelliJ IDEA
- Git / GitHub
